# 邮件列表操作与浏览器通知

- 邮件列表支持右键和键盘菜单、星标和批量操作。长按或 Ctrl+点击时显示复选框。快捷筛选支持阅读状态三档、星标两档和按邮箱的 IMAP 标签多选，在数据库分页前应用。
- 阅读工具栏可将邮件移入垃圾邮件、移回收件箱，以及查看和下载原始邮件。
- 已登录且页面保持打开时，浏览器可按设备偏好提示新到的未读收件箱邮件。首次同步和 UIDVALIDITY 重建均不会触发系统通知。
- 新增 SQLite 迁移记录文件夹首次完整同步状态。旧库中有明确同步游标的文件夹沿用原游标。其余文件夹在下一次成功同步后开始报告来信。

本次在 Windows 用本地 GreenMail 和 Chrome 验证，覆盖列表与阅读交互、实际投递后的通知、双标签页去重及窄屏显示。
