# 许可证资料

项目自身的许可见根目录 `LICENSE`（Apache-2.0），署名见 `NOTICE`。第三方代码和素材继续适用各自许可，不会因为随本项目分发而改成 Apache-2.0。

运行 `pnpm notices`，按 `pnpm licenses list --prod --json` 的实际安装结果生成网页所需的组件列表、完整许可证文件和 `THIRD-PARTY-NOTICES.txt`。包含生产依赖及其间接依赖；不把开发工具、Node.js 或操作系统镜像列为应用依赖。后二者随其各自发行物提供许可信息。构建与前端开发启动都会执行生成，不需要构建时访问上游网站。

生成目录为 `apps/web/public/legal/`，不手工编辑、不提交；Vite 会将其复制到 `apps/web/dist/legal/`，Docker 一并复制该目录。`NOTICE`、项目 `LICENSE`、Thunderbird 说明和本次构建使用的配置摘录也在其中。

部分 npm 发布包未携带许可文件，补充副本保存在此目录，固定来源记录在 `supplements.json`。这些副本从上游原样保存，未改动版权和许可正文。版本变化后需要重新核对；生成器不会静默给缺失许可的组件套用项目协议。双许可组件保留上游完整许可选项和随包文件，本项目不把其中一个选项解释为另一方授权。

这份自动清单用于归属与许可披露，不是法律审计或适用于所有分发场景的合规保证。新增依赖、复制源码或素材时，应核对对应权利和义务；不能用免责声明代替所需的许可、署名或源码提供义务。

Lucide 的随包许可注明部分图标来自 Feather；因此另附 Feather MIT 许可全文，展示为 ISC AND MIT。SQLite 的版本和公有领域声明从 better-sqlite3 实际携带的头文件提取。DOMPurify 的发行文件版权头也随许可副本保留。
